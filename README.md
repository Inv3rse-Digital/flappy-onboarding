# Flappy Onboarding

Interfaz de configuración inicial para Flappy, el sistema avanzado de IA de inv3rse.

## Ejecutar localmente

```bash
pnpm install
pnpm dev
```

La interfaz está diseñada para una pantalla de 320 × 480 px e incluye activación, conexión Wi-Fi, perfiles para niño, adulto mayor o familia, configuración regional y vinculación con la app móvil.

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
